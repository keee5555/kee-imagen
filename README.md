# Kee Imagen

支持自定义角色的中文手绘解释配图 Skill。适用于文章正文、公众号、小红书、课程与 AI 工作流。

## 安装

下载仓库中的 `kee-imagen.zip`，解压后将 `kee-imagen` 文件夹放入支持 Skill 的助手目录。例如 Codex 的 `~/.codex/skills/kee-imagen/`。安装到已有同名目录前请备份。

## 使用

提供正文与角色设定，然后说「用 kee-imagen 帮我配图」。助手先规划配图，再提供 Core 与两套适配配方，确认后逐张生成。

支持 Core 黄白手绘、儿童涂色、极简黑白漫画、小豆人涂鸦、情绪淡彩速写、复古动画概念稿。支持系列风格锁定与小红书 1080×1440 输出。

## 依赖与素材

图像生成需要宿主助手提供相应工具。公开版使用文字配方，角色图、风格参考和系列锚点由使用者自行提供。导出脚本仅适用于具有 zsh、sips 和 awk 的 macOS。

本仓库为去除个人身份、专属图片与本地项目规则后的通用版本。
